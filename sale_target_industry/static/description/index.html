⚡ Quick Workflow
  1. Assign Industries: Ensure customers have an assigned Sector/Industry (res.partner.industry).
  2. Create Target Plan: Go to Sales > Reporting > Targets by Industry > Target Plans.
  3. Add Lines: Set targets per Industry and Month.
  4. Track Progress: Actual amounts from confirmed orders calculate automatically.
  5. Analyze: Switch to the Pivot & Graph reports to visualize trends and gaps.
